Configuration Help

                

                

                    
Environment Variables Required:

                    
    
                        
  • SMTP_HOST - SMTP server hostname (default: smtp.gmail.com)
    • 
                        
  • SMTP_PORT - SMTP server port (default: 587)
    • 
                        
  • SMTP_USER - SMTP username
    • 
                        
  • SMTP_PASSWORD - SMTP password
    • 
                        
  • SMTP_FROM_EMAIL - Sender email address (default: noreply@compass.local)
    • 
                    

                    
Automatic Notifications:

                    
Configure automatic notifications in config/config.yaml:

                    
    
                        
  • notify_on_failure - Send on validation failures
    • 
                        
  • notify_on_critical - Send on critical violations
    • 
                        
  • notify_on_success - Send on validation success
    • 
                        
  • default_recipients - List of default email addresses
    •

Getting Started

                

                

                    
How to use Terraform Cloud Integration:

                    
    
                        
  1. Generate an API token from your Terraform Cloud account
    2. 
                        
  2. Enter your API token and organization name above
    3. 
                        
  3. Click "Test Connection" to verify your credentials
    4. 
                        
  4. Click "Load Workspaces" to see all workspaces in your organization
    5. 
                        
  5. Select a workspace to view details, analyze, or validate
    6. 
                    

                    
What you can do:

                    
    
                        
  • Analyze - Get detailed insights about workspace resources, patterns, and security
    • 
                        
  • Validate - Run validation rules against your workspace's current state
    • 
                        
  • View Details - See workspace configuration, variables, and recent runs
    •

Graph Visualizer Guide

                

                

                    
How to use:

                    
    
                        
  • Select a graph source (current validation, historical validation, or custom data)
    • 
                        
  • Click "Generate Graph" to create the interactive visualization
    • 
                        
  • Use mouse to pan (drag) and zoom (scroll)
    • 
                        
  • Click nodes to view resource details and dependencies
    • 
                        
  • Use search and filters to find specific resources
    • 
                        
  • Export as Mermaid or DOT format for documentation
    • 
                    

                    
Features:

                    
    
                        
  • Interactive Navigation - Pan, zoom, and click to explore
    • 
                        
  • Dependency Highlighting - See direct dependencies when selecting a node
    • 
                        
  • Type Filtering - Filter by resource type (compute, database, network, etc.)
    • 
                        
  • Search - Find resources by name or ID
    • 
                        
  • Circular Dependency Detection - Automatically identifies circular dependencies
    • 
                        
  • Export Options - Export as Mermaid or Graphviz DOT format
